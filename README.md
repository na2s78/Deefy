## Fonctionnalités

| N° | Fonctionnalité | Fait |
|----|----------------|------|
| 1 | Mes playlists | oui |
| 2 | Afficher une playlist | oui |
| 3 | Ajouter une piste | oui |
| 4 | Créer une playlist vide | oui |
| 5 | Afficher la playlist courante | oui |

## Base de données

J'ai utilisé la base fournie (deefy_db.sql), sans modification. Elle est dans sql/deefy.sql.
Les pistes de cette base n'ont pas de fichier mp3, il faut en ajouter une pour tester la lecture.

## Installation

Copier conf/db.config.ini.template en conf/db.config.ini et mettre ses identifiants de BD.
Le dossier audio/ doit être accessible en écriture pour l'upload.
